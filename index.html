1. 주제에 대한 관련 지식

Brute Force Attack

가능한 모든 비밀번호 조합을 대입하여 계정을 탈취하는 공격 방식이다. 비밀번호가 짧거나 단순할수록 공격 성공 가능성이 높아진다.

Dictionary Attack

사전에 존재하는 단어나 자주 사용되는 비밀번호 목록을 활용하여 계정을 공격하는 방식이다.

Password Policy

비밀번호 길이, 대문자, 숫자, 특수문자 포함 여부 등을 규정하여 보안성을 향상시키는 정책이다.

비밀번호 강도 평가

비밀번호의 길이와 문자 구성 요소를 분석하여 보안 수준을 판단하는 방법이다.

3. 프로그램 제작 (소스코드)

C 언어로 구현된 비밀번호 강도 분석 프로그램이다. 입력된 문자열을 분석하여 보안 점수를 계산한다. 

#include <stdio.h>
#include <string.h>
#include <ctype.h>

int main()
{
    char password[100];

    int length;
    int hasUpper = 0;
    int hasDigit = 0;
    int hasSpecial = 0;
    int score = 0;

    printf("비밀번호를 입력하세요 : ");
    scanf("%s", password);

    length = strlen(password);

    for(int i = 0; i < length; i++)
    {
        if(isupper(password[i]))
            hasUpper = 1;

        if(isdigit(password[i]))
            hasDigit = 1;

        if(!isalnum(password[i]))
            hasSpecial = 1;
    }

    if(length >= 8)
        score++;

    if(hasUpper)
        score++;

    if(hasDigit)
        score++;

    if(hasSpecial)
        score++;

    printf("\n===== 분석 결과 =====\n");

    printf("길이 : %d자\n", length);

    printf(hasUpper ? "대문자 포함\n" : "대문자 없음\n");
    printf(hasDigit ? "숫자 포함\n" : "숫자 없음\n");
    printf(hasSpecial ? "특수문자 포함\n" : "특수문자 없음\n");

    printf("\n보안 등급 : ");

    if(score <= 1)
        printf("매우 약함");
    else if(score == 2)
        printf("약함");
    else if(score == 3)
        printf("보통");
    else
        printf("강함");

    return 0;
}

5. 느낀 점 및 결론

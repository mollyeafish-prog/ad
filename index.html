연구 동기

현대 사회에서는 대부분의 서비스가 계정 기반으로 운영되고 있으며, 비밀번호는 개인정보와 계정을 보호하는 가장 기본적인 보안 수단이다. 하지만 많은 사용자가 단순하거나 예측 가능한 비밀번호를 사용하여 계정 탈취, 개인정보 유출 등의 보안 사고가 발생하고 있다.


본 연구에서는 사용자가 입력한 비밀번호의 보안 강도를 분석하고, 안전한 비밀번호 생성 기준을 제시하는 프로그램을 개발하고자 하였다.

C 언어 소스코드

비밀번호의 길이와 문자 구성 요소를 분석하여 보안 등급을 판정하는 프로그램이다. 

#include <stdio.h>
#include <string.h>
#include <ctype.h>

int main()
{
    char password[100];

    int length;
    int hasUpper = 0;
    int hasDigit = 0;
    int hasSpecial = 0;
    int score = 0;

    printf("비밀번호를 입력하세요 : ");
    scanf("%s", password);

    length = strlen(password);

    for(int i = 0; i < length; i++)
    {
        if(isupper(password[i]))
            hasUpper = 1;

        if(isdigit(password[i]))
            hasDigit = 1;

        if(!isalnum(password[i]))
            hasSpecial = 1;
    }

    if(length >= 8)
        score++;

    if(hasUpper)
        score++;

    if(hasDigit)
        score++;

    if(hasSpecial)
        score++;

    if(score <= 1)
        printf("매우 약함");
    else if(score == 2)
        printf("약함");
    else if(score == 3)
        printf("보통");
    else
        printf("강함");
}
